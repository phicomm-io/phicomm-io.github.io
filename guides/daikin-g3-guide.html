G3 安装、更新与恢复

屏幕编排与外观 · 天气、提醒与 API · 启动与诊断 · 开发资料 · 原厂备份

G3 是带屏幕的 BRY88BBA15G，包含 ESP32 联网固件和独立的屏幕 MCU 固件。默认设备名为 DAIKIN G3；修改过的自定义名称会保留。

区分代际

代际 实际型号 甲醛扩展孔 屏幕 下载分组
G1 BRY88AA151K 无 无 大金空气质量检测（1/2代）
G2 BRY88AB151K 相比 G1 增加 无 大金空气质量检测（1/2代）
G3 BRY88BBA15G 依实际扩展模块 增加屏幕 大金空气质量检测（3代）

G1/G2 的默认名称为 DAIKIN G1/G2。代际名称用于辨认产品；选固件还需核对板型。早期 BRY88AA151K 的引脚、TVOC 与通用 BRY88AX151K 固件不同，不能只根据 G1 标签选择镜像。G1/G2 的安装与适配范围见对应指南。

屏幕设置

打开设备网页的“设置 → 屏幕”，按标签配置：

  • 布局：组合时钟、数值、文字、图表、天气与提醒，支持拖动、尺寸调整、撤销与本地草稿。全页组件可隐藏标题。
  • 外观：六组主题、自定义配色、组件独立配色、壁纸与透明度。
  • 显示：亮度、休眠时间、每周调光计划、休眠页及中文/英文。设备名和自定义标题不会自动翻译。
  • 天气与提醒：配置天气提供商、位置、定时提醒或 API 推送；Open-Meteo 无需 Key。默认关闭 TLS 证书校验，可手动启用。
  • 资源与升级：可选高清中文字库、屏幕 MCU 串口 OTA，以及最小服务窗口的“立即继续启动”和“保持最小服务”。
  • 高级：AM1008L 模块 SET（PD12）控制与诊断。

屏幕采用顶部全宽分段页码条、16 px 外边距和 8 px 组件间距，网页预览使用同样的尺寸。换页条在「屏幕 → 外观」可选 6、12、20 px，默认 12 px。

本地曲线可选 32、64、128、256 点。每分钟采样，历史不足时铺满绘图区，缺测保留断点；MCU 重启后重新积累。外部 API 序列维持每条 32 点的协议。

下载与更新

固件与资源下载提供 G3 最新兼容版本，包括 ESP32 签名升级包、原厂迁移用 raw 应用、屏幕 MCU 应用、可选字库和免拆迁移工具。G1/G2 镜像不能用于 G3。

从原厂免拆迁移

下载并解压 daikin_G3_migration.tar.gz，按最新中英文教程操作。需要有蓝牙的 Linux 或 Mac、设备能访问的 Docker 服务主机，以及仅对本设备生效的 DNS 配置权限。重新发布的 RC6 包含两种配网工具；旧包的 Linux 用户可另取教程目录中的 provision_linux.py 和 wifi.example.json。Linux 使用 BlueZ 与系统 Python 的 python3-dbus，也可通过 SSH 在附近主机运行。

  1. 用实际 Wi-Fi STA MAC 和服务主机 IP 创建临时服务，配置仅本机的三个域名；默认不提供更新。蓝牙地址和虚拟网关 MAC 不能代替设备 STA MAC。
  2. 短按背面网络键进入配网，用工具发送 2.4 GHz Wi-Fi 和虚拟网关标识。不要长按复位。配网成功后蓝牙会关闭，需要重发时再次短按。
  3. 启动一个带 --empty-gateway --weather-code 1 的网关应答器，等待快照、天气、网关登录、滤网及错误查询均得到应答。原厂 SV.04.00.01.00 收到空天气会持续重试；天气码是临时占位，温湿度与 PM2.5 保留缺测标记。
  4. 校验 RC6 的 daikin_BRY88BBA15G.ota.bin.raw，显式启用升级后发送一次仅 ESP32 的升级命令。
  5. 重新打开设备网页，核对版本、联网和传感器读数，撤销临时 DNS 并停止服务。

第一阶段保留原厂屏幕 MCU 和引导区。网络迁移依赖原厂下载流程仍可运行；不需要访问大金服务器。保留原厂 MCU 时也可配置当前天气，再按下节升级社区屏幕。

社区版在线更新

ESP32：打开“设置 → 固件更新”，选择更新源并检查版本，阅读升级内容后安装。RC 版本检查独立候选通道；下载时校验型号、签名、长度和 SHA-256。上传自己的 raw 应用可使用明确标出的未签名救援入口。

屏幕 MCU 与字库：在局域网直接打开设备网页，进入“屏幕 → 资源与升级 → 在线更新”。检查版本后分别下载并安装屏幕应用或字库；网页核对文件大小，ESP32 再校验哈希并暂存，完成后才请求 MCU 安装。当前远程云端通道支持控制和 ESP32 更新，屏幕大文件上传需要本地直连。

在屏幕下载获取同一版 RC6 的 ESP32、完整屏幕应用与免拆迁移工具。先更新 ESP32，再使用包内新脚本安装屏幕应用。

新脚本与配套新 ESP32 可直接向原厂 MCU 发送完整的 daikin_G3_screen.bin，不要求先安装恢复镜像、引导备份或原厂版本白名单。新 MCU 应用也取消本地引导 MD5 白名单。解压配套工具，安装 Python 的 msgpack 后执行：

python3 -m pip install msgpack
python3 screen/flash_screen.py --url http://DEVICE_IP --image daikin_G3_screen.bin --mode install --log install.jsonl

工具自动选择原厂串口安装或社区 MCU 暂存／激活路径，保留型号、向量、长度、摘要及暂存回读检查。设置了管理密码时通过 IOTCLOUD_AUTH=admin:密码 提供。完成后日志应显示新会话和实际运行应用的 MD5。

保存引导备份是可选操作：社区 MCU 可使用 screen/backup_screen_boot.py 双读前 80 KiB；已有备份可配合 --boot-backup 目录 --reuse-boot-backup 检查复用。原厂 MCU 没有该读出接口。恢复镜像仍可用于最小服务诊断，安装后黑屏是预期，但不再是首次安装的必经步骤。

本次重新发布的 RC6 已包含新脚本、ESP32 和 MCU 应用。之前安装的旧 MCU 仍执行内部引导检查，迁移到新版前需满足该版本条件。所有屏幕 OTA 保留原厂引导区。原厂引导的复制范围需与目标硬件一致；应用包不能当作整片镜像，安装时保持稳定供电。

屏幕启动时先开放最小恢复服务，ESP32 默认在 5 秒后自动继续启动。在“资源与升级”关闭“启动 5 秒后自动继续”，可保留完整的 30 秒窗口，设置断电后仍保留。“保持最小服务”优先于自动启动，也可随时“立即继续启动”；故障维护不会自动退出，仍需安装修复固件。通信和 OTA 先于业务界面启动。更新期间临时降到 10% 亮度，受显示上限约束，不改保存亮度；原厂引导安装重启时会短暂黑屏。当前固件保留原厂引导的开机门控，完全断电后可能需要短触正面按键；来电自动启动未修改引导实现。

可选高清字库

daikin_G3_zh32.iotfnt 包含 6863 个字形，32 px、2 bpp 灰阶，在外部 SPI NOR 中保存并校验后缓存到 SDRAM。字库上传耗时较长，按网页进度等待提交完成。字库不随应用 OTA 重写。启动期间显示 LVGL 加载动画、字库进度和传感器就绪数量，仍可翻页；未连接传感器和失败资源会限时结束等待并降级。启动时先完成字库加载和校验，再开启传感器，降低初始化的同时负载；三个传感器串口继续使用独立中断缓冲。每次屏幕启动后会先显示内置精简字体，完整字库后台加载完成后自动刷新；加载期间，自定义地点或标题中的部分汉字可能暂时显示占位符。

NOR 默认使用四线硬件 SFC，字库分批读取时同步校验。当前真机的 1.64 MB 字库加载耗时约 1.3 秒，包含后台调度和校验。只有 ESP32 在诊断启动窗口显式选择后，才使用单线 SFC 或 GPIO；硬件异常不会自动切换总线。NOR 不可用、数据损坏或读取超时时降级为内置字体和缺字占位；传感器、通信与恢复服务继续运行。屏幕 MCU 应用约占 198 KiB，412 KiB 应用分区余约 214 KiB。
