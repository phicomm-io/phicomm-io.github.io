G3 安装、更新与恢复

刷机教程 · 屏幕编排与外观 · 天气、提醒与 API · 启动与诊断 · 开发资料 · 原厂备份

G3 是带屏幕的 BRY88BBA15G，包含 ESP32 联网固件和独立的屏幕 MCU 固件。默认设备名为 DAIKIN G3；修改过的自定义名称会保留。

区分代际

代际 实际型号 甲醛扩展孔 屏幕 下载分组
G1 BRY88AA151K 无 无 大金空气质量检测（1/2代）
G2 BRY88AB151K 相比 G1 增加 无 大金空气质量检测（1/2代）
G3 BRY88BBA15G 依实际扩展模块 增加屏幕 大金空气质量检测（3代）

G1/G2 的安装与板型选择见对应指南。G1/G2 镜像不能用于 G3。

下载配套版本

从固件与资源下载选择最新兼容 G3 发布，一并获取该发布的 ESP32、屏幕 MCU 和 daikin_G3_migration.tar.gz。工具包包含 Linux 与 macOS 配网工具以及可选的屏幕安装脚本。

本教程使用当前 RC6，配套屏幕 MCU 为 1.0.0-rc.6-55e52f。请使用下载页当前发布的完整工具包与固件，或更新的兼容版本。核对发布页的源码版本和 SHA256SUMS，保留配置备份。

从原厂免拆迁移

完整操作见刷机教程 → 原厂免拆安装 ESP32，分别提供 Windows、Linux、macOS 步骤；串口安装和屏幕 J-Link 恢复也在同一教程。

解压当前 daikin_G3_migration.tar.gz。需要带蓝牙的 Linux 或 Mac、设备可访问的 Docker 服务主机，以及仅对本设备配置 DNS 的权限。Windows 通过 SSH 操作附近的蓝牙 Linux 主机。

  1. 用设备实际 Wi-Fi STA MAC 和服务主机 IP 创建临时服务，配置教程中的三个域名；服务初始不提供更新。
  2. 短按背面网络键进入配网，发送 2.4 GHz Wi-Fi 和虚拟网关配置。配网后蓝牙会关闭，需要重发时再次短按；长按会触发复位。
  3. 启动一个带 --empty-gateway --weather-code 1 的应答器，等待天气、网关登录、滤网和错误查询均得到应答。
  4. 校验同一发布的 daikin_BRY88BBA15G.ota.bin.raw，启用升级并发送一次仅 ESP32 的升级命令。安装期间保持稳定供电。
  5. 打开设备网页，核对版本、设备身份、联网和传感器读数，随后撤销临时 DNS 并停止服务。

此阶段保留原厂屏幕 MCU。保留原厂屏幕也能使用当前天气；要使用编排、主题和提醒，再安装社区屏幕 MCU。

社区版在线更新

ESP32

打开“设置 → 固件更新”，检查并安装最新兼容版本。RC 构建使用独立候选通道。在线更新校验型号、签名、长度和 SHA-256；自行构建的 raw 应用可使用未签名救援入口。

配套社区屏幕会在 ESP32 OTA 期间暂停 PM2.5/TVOC 模块，重启后自动恢复。更新完成后确认这两项读数重新刷新。

屏幕 MCU：在线或上传安装

先更新配套 ESP32，在局域网直接打开设备网页，进入“设置 → 屏幕 → 资源与升级”。首次从原厂屏幕安装与后续更新使用相同入口，任选一种方式：

  1. 在线安装：点击“检查更新”，再点击“安装屏幕更新”。
  2. 文件安装：从同一发布下载 daikin_G3_screen.bin，选择文件并点击“上传并安装”。

保持供电，等待“屏幕固件已安装并正常启动”。安装自动完成校验、传输和激活，保留原厂引导区；首次安装无需预先备份引导或安装恢复镜像。安装完成后核对屏幕版本、页面和传感器读数。字库可另行安装。

命令行可使用当前工具包内的安装脚本。进入解压后的 daikin-g3-migrate 目录，将屏幕镜像放在它的上一级，安装 Python msgpack 后执行：

python3 -m pip install msgpack
python3 screen/flash_screen.py --url http://DEVICE_IP --image ../daikin_G3_screen.bin --mode install --log install.jsonl

设置管理密码后，通过环境变量 IOTCLOUD_AUTH=admin:密码 提供认证。可选引导备份和恢复镜像用法见开发资料。

屏幕设置与按键

  • 布局：组合时钟、数值、文字、图表、天气与提醒，支持拖动、调整尺寸、撤销和本地草稿。
  • 外观：主题、组件配色、壁纸与透明度。
  • 显示：亮度、休眠、每周调光计划、休眠页与中文/英文。
  • 天气与提醒：配置提供商、位置、定时提醒或 API 推送。
  • 资源与升级：字库、屏幕 MCU 更新和启动维护窗口。

正面键短按切页，熄屏后第一次短按唤醒；持续长按约 3 秒关机。关机后松开，再长按约 2 秒开机。背面网络键用于配网。

屏幕启动时先开放维护窗口，默认 5 秒后继续启动。在资源页关闭“启动 5 秒后自动继续”，可使用完整 30 秒窗口；也可选择“保持最小服务”或“立即继续启动”。故障维护需安装修复固件，见启动与诊断。

可选高清字库

daikin_G3_zh32.iotfnt 提供 6863 个 32 px 中文字形。在“资源与升级”在线安装或上传文件，等待进度完成。普通 MCU 更新保留字库，无需重复上传。

每次启动先显示内置精简字体，完整字库在后台加载，完成后自动刷新。期间部分自定义汉字可能暂显占位符；查看资源状态和进度即可。字库不可用时使用内置字体，传感器与更新服务继续运行。
