G3 安装、更新与恢复

屏幕编排与外观 · 天气、提醒与 API · 启动与诊断 · 开发资料 · 原厂备份

G3 是带屏幕的 BRY88BBA15G，包含 ESP32 联网固件和独立的屏幕 MCU 固件。默认设备名为 DAIKIN G3；修改过的自定义名称会保留。

区分代际

代际 实际型号 甲醛扩展孔 屏幕 下载分组
G1 BRY88AA151K 无 无 大金空气质量检测（1/2代）
G2 BRY88AB151K 相比 G1 增加 无 大金空气质量检测（1/2代）
G3 BRY88BBA15G 依实际扩展模块 增加屏幕 大金空气质量检测（3代）

G1/G2 的默认名称为 DAIKIN G1/G2。代际名称用于辨认产品；选固件还需核对板型。早期 BRY88AA151K 的引脚、TVOC 与通用 BRY88AX151K 固件不同，不能只根据 G1 标签选择镜像。G1/G2 的安装与适配范围见对应指南。

屏幕设置

打开设备网页的“设置 → 屏幕”，按标签配置：

  • 布局：组合时钟、数值、文字、图表、天气与提醒，支持拖动、尺寸调整、撤销与本地草稿。全页组件可隐藏标题。
  • 外观：六组主题、自定义配色、组件独立配色、壁纸与透明度。
  • 显示：亮度、休眠时间、每周调光计划、休眠页及中文/英文。设备名和自定义标题不会自动翻译。
  • 天气与提醒：配置天气提供商、位置、定时提醒或 API 推送；Open-Meteo 无需 Key。默认关闭 TLS 证书校验，可手动启用。
  • 资源与升级：可选高清中文字库、屏幕 MCU 串口 OTA，以及最小服务窗口的“立即继续启动”和“保持最小服务”。
  • 高级：AM1008L 模块 SET（PD12）控制与诊断。

屏幕采用顶部全宽分段页码条、16 px 外边距和 8 px 组件间距，网页预览使用同样的尺寸。换页条在「屏幕 → 外观」可选 6、12、20 px，默认 12 px。

本地曲线可选 32、64、128、256 点。每分钟采样，历史不足时铺满绘图区，缺测保留断点；MCU 重启后重新积累。外部 API 序列维持每条 32 点的协议。

下载与更新

固件与资源下载提供 G3 最新兼容版本，包括 ESP32 签名升级包、原厂迁移用 raw 应用、屏幕 MCU 应用、可选字库和免拆迁移工具。G1/G2 镜像不能用于 G3。

从原厂免拆迁移

下载并解压 daikin_G3_migration.tar.gz，按包内中英文教程操作。需要一台有蓝牙的 Mac、同网段运行 Docker 的电脑，以及仅对本设备生效的 DNS 配置权限。

  1. 用设备 MAC 和电脑的局域网 IP 创建临时服务；默认不提供更新。
  2. 短按背面网络键进入配网，用工具发送 Wi-Fi 和虚拟网关标识。不要长按复位。
  3. 只对该设备重定向教程列出的三个域名，确认日志中的关联与版本查询。
  4. 校验 RC6 的 daikin_BRY88BBA15G.ota.bin.raw，显式启用升级后发送一次仅 ESP32 的升级命令。
  5. 重新打开设备网页，核对版本、联网和传感器读数，撤销临时 DNS 并停止服务。

第一阶段保留原厂屏幕 MCU 和引导区。网络迁移依赖原厂下载流程仍可运行；不需要访问大金服务器。

社区版在线更新

ESP32：打开“设置 → 固件更新”，选择更新源并检查版本，阅读升级内容后安装。RC 版本检查独立候选通道；下载时校验型号、签名、长度和 SHA-256。上传自己的 raw 应用可使用明确标出的未签名救援入口。

屏幕 MCU 与字库：在局域网直接打开设备网页，进入“屏幕 → 资源与升级 → 在线更新”。检查版本后分别下载并安装屏幕应用或字库；网页核对文件大小，ESP32 再校验哈希并暂存，完成后才请求 MCU 安装。当前远程云端通道支持控制和 ESP32 更新，屏幕大文件上传需要本地直连。

首次从原厂屏幕迁移需要分两步。下载页的 daikin_G3_recovery.bin 仅提供最小恢复服务，安装后黑屏是预期；daikin_G3_screen.bin 是完整界面。原厂 MCU 版本须为 SV.04.00.01.00，ESP32 已运行社区版。解压迁移工具，安装 Python 的 msgpack 后，在工具目录执行，替换设备地址：

python3 -m pip install msgpack
python3 screen/flash_screen.py --url http://DEVICE_IP --image ../daikin_G3_recovery.bin --mode factory-bootstrap --log bootstrap.jsonl
python3 screen/backup_screen_boot.py --url http://DEVICE_IP --output boot-backup --hold
python3 screen/flash_screen.py --url http://DEVICE_IP --image ../daikin_G3_screen.bin --mode install --boot-backup boot-backup --log install.jsonl

保留已有原厂备份；恢复镜像启动后会将前 80 KiB 引导区读取两次，工具确认内容和校验一致后才允许安装完整应用。设置了管理密码时，通过环境变量 IOTCLOUD_AUTH=admin:密码 提供。日志核对实际运行镜像的 MD5。后续未修改引导区可复用该备份，命令增加 --reuse-boot-backup；也可在网页保存引导区。应用包不能当作整片镜像，所有屏幕 OTA 均保留现有引导区。

屏幕启动时先开放最小恢复服务，ESP32 默认在 5 秒后自动继续启动。在“资源与升级”关闭“启动 5 秒后自动继续”，可保留完整的 30 秒窗口，设置断电后仍保留。“保持最小服务”优先于自动启动，也可随时“立即继续启动”；故障维护不会自动退出，仍需安装修复固件。通信和 OTA 先于业务界面启动。更新期间临时降到 10% 亮度，受显示上限约束，不改保存亮度；原厂引导安装重启时会短暂黑屏。当前固件保留原厂引导的开机门控，完全断电后可能需要短触正面按键；来电自动启动未修改引导实现。

可选高清字库

daikin_G3_zh32.iotfnt 包含 6863 个字形，32 px、2 bpp 灰阶，在外部 SPI NOR 中保存并校验后缓存到 SDRAM。字库上传耗时较长，按网页进度等待提交完成。字库不随应用 OTA 重写。启动期间显示 LVGL 加载动画、字库进度和传感器就绪数量，仍可翻页；未连接传感器和失败资源会限时结束等待并降级。三个传感器串口独立使用中断缓冲，字库加载不阻塞收数。每次屏幕启动后会先显示内置精简字体，完整字库后台加载完成后自动刷新；加载期间，自定义地点或标题中的部分汉字可能暂时显示占位符。

字库使用 SFC 硬件读取，并在分批读取时同步校验。当前真机的 1.64 MB 字库加载耗时约 14 秒；这是后台加载和校验的总耗时。硬件读取比较失败或控制器异常时退回 GPIO，NOR 不可用、数据损坏或读取超时再降级为内置字体和缺字占位；传感器、通信与恢复服务继续运行。屏幕 MCU 应用约占 196 KiB，412 KiB 应用分区余约 216 KiB。
