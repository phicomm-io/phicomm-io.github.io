自动调速与联动

在 A1 添加 M1／大金的实际设备 ID 和可选内网 IP，按绑定页建立授权会话，再在自动调速页选择指标、开／关条件与风速范围。MQTT 可用于建立会话，已配对的局域网数据通过 UDP；不需要保持网页打开。选择自动模式本身不会强制开机，关机时保留模式。数据过期时使用已配置的离线策略，不将无效读数当作零。新风变体可分别设置两路策略；普通 A1 不显示未实现的硬件控制。

A1 的定时、倒计时和传感器联动是不同入口，详见 风机与联动操作。下表的对外数值是主风机当前生效输出百分比，不是 RPM，也不是外接新风风机转速。

设备 ID 与字段 ID

device_id 使用本机工厂 MAC 的 12 位小写十六进制形式，如 aabbccddeeff。在设备信息／诊断页查看实际 ID，或从同一 MQTT 账户的设备列表中选择。字段 ID 大小写敏感，按下表填写。

字段 ID 含义 单位
fan_speed_percent 主风机生效输出 %

通过 MQTT 供 M1 显示

  1. 来源设备与 M1 都配置为项目二进制 MQTT 模式，连接同一个外部 broker、同一个 MQTT 账户。该账户的 ACL 需要允许读取自己的传感器主题。仅填相同服务器、使用不同账号，通常不能互相发现。
  2. 在 M1「设置 → 常规 → 设备屏幕用户读数」中选择甲醛区域或 PM2.5 区域，来源选「其他 MQTT 设备」。选择实际来源设备和字段；找不到时先确认两端都支持传感器字段协议并已上报。
  3. 保存来源、单位、显示方式和有效时间，启用用户读数；需要时按已配置的双击动作整体切换原始／用户读数。默认有效时间为 20 秒；超过有效时间或收到无效值时，该区域回到原始读数。
  4. 网页、云平台可关闭。只要两台设备与 broker 正常运行，来源发布、M1 订阅和显示继续工作。

M1 是三位数的固定段码屏，不能显示任意单位文字。PM2.5 区域只显示整数；甲醛区域的小数点固定在第一位后。显示 W、V、A 或 ppm 等外部数据时，按需要隐藏原来的「甲醛／PM2.5」字样及 mg/m³、µg/m³ 单位。超量程与显示方式见 M1 操作说明。

协议与排查

传感器字段描述和数值采用 MessagePack schema 3，分别通过 metadata 和 state 发布。主题为 phicomm/v2/u_<账户编码>/sensor/<device_id>/metadata 与 /state；账户编码由固件按用户名生成，空用户名使用本地作用域。元数据保留，数值不保留；启动标识、序号、字段版本、有效标志与读数年龄用于拒绝旧数据。调试工具需支持 MessagePack 解码。

设备离线、字段不存在、单位不匹配或读数过期时，检查来源上报与 M1 有效期。无效或缺失数据按不可用处理。内网 UDP 配对、网页管理认证与 MQTT broker 认证相互独立。开发者接口见 openiot 协议文档。
