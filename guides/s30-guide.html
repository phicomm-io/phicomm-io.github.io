S30-V1B 常见功能

本文集中说明安装后的使用、升级和恢复。首次安装按 刷机方法选择原厂免拆或串口；来电策略、灯语和计量倍率见 特色功能；功率条件与 M1 远程显示见 自动化与字段 ID。

配网与访问

  1. 未配置网络时，连接 S30M_V1B_XXXXXX 热点；XXXXXX 是本机工厂 MAC 后六位的大写十六进制。初始热点无需密码。
  2. 浏览器打开 http://192.168.0.1，在设置中填写可用的 2.4 GHz Wi-Fi 名称和密码并保存。
  3. 设备重启并联网后，将手机或电脑切回同一局域网，在路由器中找到设备获得的 IP，再用浏览器打开该地址。路由器中显示的主机名为 iotcloud-s30-v1b-xxxxxx，后缀为 MAC 后六位的小写形式。

初始网页管理密码为空，直接进入页面，不需要登录。设置管理密码后才需要认证；使用 HTTP Basic 的客户端用户名为 admin。管理密码独立于 Wi-Fi 密码和 MQTT 账号密码。忘记管理密码需要恢复出厂设置，仅重置 Wi-Fi 不会清除它。

开关与设置

首页提供一路插座开关、电压（V）、电流（A）、有功功率（W）及累计电量；iotcloud 设备卡和设备详情也展示电压、电流，复用同一份状态，不增加计量轮询。短按设备按钮也可切换输出，蓝灯随输出通断。童锁开启后屏蔽短按，但仍可通过网页控制及使用长按恢复手势。

设置中可修改设备名称、插座名称、上电开关策略、指示灯、童锁、上报间隔、Wi-Fi、MQTT 和管理密码。已发布 RC4 支持来电关闭／开启，开发版增加“保持”，具体语义见 特色功能。短按后的约 1.5 秒内，远程开关可能返回忙，避免立即覆盖本地操作。

升级

安装本固件后，可在网页的升级设置中输入本设备 .rbl 文件的 HTTP 下载地址。设备必须能够直接访问该地址；下载文件与同版本校验值应来自可信来源。升级期间暂停 MQTT、UDP、扫描及新的控制/配置操作，保留 HTTP 状态查询；失败后恢复服务，成功后自动重启。重启后的插座输出按已保存的上电策略执行，请先确认负载允许中断和重新供电。

当前仅支持 URL 下载，不支持本地文件上传。RBL 无数字签名，请校验 SHA-256 并使用可信下载源；其他设备的 .ota.bin 包不适用。原厂首次安装及串口恢复见免拆与串口刷机。

将 RBL 和校验文件下载到同一目录并校验。在这个目录运行 python3 -m http.server 8000 --bind 0.0.0.0，允许防火墙放行该端口，在设备网页填写 http://<电脑的局域网IP>:8000/BL2028N_OTA_<版本>.rbl。不要填写 localhost，也不要填写下载说明页面的地址。升级完成后停止临时 HTTP 服务。

恢复

操作 松手后的动作
短按 切换插座输出；童锁开启时忽略
按住 1 秒至不足 5 秒 无重置动作
按住至少 5 秒、不足 10 秒 重置 Wi-Fi 并重启
按住至少 10 秒 恢复出厂设置并重启

长按灯语与 TC1 保持相同节奏：从按满 1 秒起，每满一秒闪一次、亮约 160 ms。第 1–4 次为蓝灯，第 5–9 次为红灯，第 10 次起红蓝同步。松手后恢复普通灯效；重置在松手时执行，按到 5 秒时不会立即重启，因此可以继续按住进入 10 秒手势。

Wi-Fi 重置清除主、备用网络，保留产品设置、MQTT、管理密码、配对、校准系数和累计电量。出厂恢复同时清除这些设置及累计值，回到默认上电关闭状态。重置后重新连接设备热点配网。

MQTT 与 Home Assistant

在设置中填写 MQTT broker 地址、端口和所需账号密码。当前支持 TCP MQTT。Home Assistant 可发现一路插座、电压、电流、功率、累计电量及计量有效性六个实体；未配置 MQTT 不影响本地网页使用。

HTTP、MQTT 和 UDP 业务采用项目 openiot 的 MessagePack / CBOR 二进制协议，JSON 仅用于 Home Assistant。协议主题、配对权限和接口见仓库 BL2028N/README.md。MQTT 使用 broker 账号认证，UDP 需要配对。

灯语与计量校准已整理到 S30-V1B 特色功能。
