资源来源

刷机教程中的图片与工具保存在本站 guides/assets/ 目录。SHA256SUMS 包含图片与安装包校验和。

文件 来源
images/tc1-ota-*.png、images/tc1-stock-*.png、images/tc1-community-ap.png 用户提供的 TC1 免拆刷机操作截图，裁剪保留路由器、网卡、TFTP、原厂识别及首启热点的关键区域
tools/tc1-no-disassembly/mico_ota.bin 与免拆主教程相同的已验证镜像快照（原始镜像 SHA-256：005b5c4d8a1bb4e70b1b6aa84f1c403e648d3c2d4d683a067a22193543050735），追加其 16 字节二进制 MD5；固定教程文件，不随最新 Release 自动替换
tools/tc1-no-disassembly/tftp-trigger.bin 按免拆主教程生成的 397 字节触发文件，仅用于 TC1 A1 原厂 1.0.0.26，不是通用升级包
images/emw3080-pins.png 庆科官网 EMW3080 引脚原图，保留原图内容，透明背景转为白色
images/emw3080-swd-pins.png 庆科 EMW3080 官方烧录说明中的 SWD 模块引脚原图
images/tc1-a1-module.png、images/tc1-a1-test-points.png 用户提供的 TC1 A1 模组与工厂测试点标注图
images/a1-jlink-points.png 用户提供的 A1 空气净化器新版 J-Link 接线标注图（DIO 上、CLK 下）
images/m1-scd40-wiring.png 用户提供的 M1 外接 SCD40 实物接线图，手写 7 / 8 为 GPIO 信号名
tools/emw3080-openocd.zip、tools/emw3080-openocd/ 本项目的 Python 3 校验、切分、烧录脚本与新版 MX1290 配置；不含第三方二进制与固件。烧录仍需 zA1 原工具包内配套的编程器及脚本
images/jlink-swd.png SEGGER 官方 SWD 接口图，由 SVG 转为白色背景 PNG
images/flashplus-config.png EMW3031 / FlashPlus 工具说明 PDF，第 2 页配置区域裁剪；仅用于识别芯片与 Flash 配置，擦除及校验选项以本项目教程为准
tools/FlashPlus_v1.0.10.msi Marvell FlashPlus v1.0.10，IoTDevice 工具镜像，安装包保持原样

DAIKIN 与读数参考

DAIKIN 引脚与 PM2005 / PM2105 协议参考 louliangsheng/daikin-air-sensor。PM2.5 与 PM10 来自同一帧的不同字段。TVOC 使用 SGP30 原生 ppb 输出，≤300 ppb 是沿用本设备指示灯阈值的产品通风参考；参见 Sensirion SGP30 数据手册与MOX 输出解释，不将该参考作为健康合格限值。颗粒物显示分段参考 HJ 633—2026 表 3，瞬时值并非按标准计算的 AQI。
