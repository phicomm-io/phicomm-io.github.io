固件更新

本页说明已经运行社区固件后的网页 OTA 更新。原厂设备先按对应首刷指南安装；M1 可使用 内网免拆迁移，首次必须从 0.9.21 或更新版本开始，不能直接套用本页的社区签名包上传步骤。

本页以 v1.0.0-rc 候选版本为当前使用基线，0.9.x 保留为历史归档；v1.0.0 稳定版尚未发布。下载时核对候选版本标签、型号和变体。

M1 有两颗 MCU。 本文更新的是 EMW3080 Wi-Fi 联网模块，不会同时更新与传感器通信的 ATSAMD20G18A 主控。双区域用户读数、双击等功能需配套开源主控 v1.0.0-rc；既有功能的最低版本见主控功能与版本条件，独立升级按主控网络升级教程操作。

通过设备网页在线检查

A1、M1、TC1 的正式构建提供 GitHub Pages HTTPS、境内 HTTP 和境外 HTTP 更新来源。在固件设置的更新页面选择来源后点击检查：

  • 界面明确区分发现新版本、已经是最新版本和网络失败三种结果。
  • 网络失败时可切换来源重试。
  • 确认型号、版本和发布说明后，手动点击下载并安装。设备不会因为检查更新而自动安装。

可以直接查看所选版本的发布说明。下载中可点击「终止下载」；网络超时或下载失败后会恢复日常服务，重新开始时从头下载。进入最终提交阶段后不能终止。

查看跨版本升级差异

打开官网 Release Log 的升级差异，选择型号、固件类型、当前版本和目标版本。说明按实际发布链汇总；资料待审核、翻译缺失或固件归档不一致时会明确停止，不用最新版说明代替完整差异。

也可手动输入内网地址并读取一次设备信息。网页管理密码仅用于本次请求，读取失败仍可手动选择；查询不会检查或安装固件。旧设备的发布说明入口继续显示单版本原文。

完整版与精简版

DAIKIN BRY88AX151K 在 v1.0.0-rc 提供 full 普通版和独立的 hub 中枢版；两者均自动探测 PM2005 / PM2105 及可选甲醛模块。使用下文的本地文件升级，不提供在线检查或 URL 下载。普通 OTA 必须匹配当前变体；full → hub 仅通过中枢切换流程操作，不支持直接 hub → full OTA。

默认文件是完整版，设备自带完整操作页面。文件名带 -no-frontend-resources 的精简版仍保留离线配网、首次 MQTT 配置和网页密码设置，可在设备热点或已联网地址打开；日常控制和完整设置通过本地设备管理或 IoTCloud 使用。两种页面保持相同风格。

在线检查保持当前版本类型；手动切换版本类型时请选择同一产品的对应签名包。精简版不需要先配置 MQTT 才能配网。

选择正确的文件

文件 用途
.ota.bin.signed 签名 OTA 包，用于网页上传与 MQTT/URL 安装，强制验证 P-256/SHA-256 签名
.ota.bin.raw 原生镜像，用于明确适配的首次迁移或无签名救援；M1 原厂迁移须使用 0.9.21 起的完整版
.all.bin 完整镜像，用于有线刷机。不要当作 OTA 上传

在 项目主页与历史版本归档 选择「本站归档（GitHub）」下载对应型号的文件，并按同版本 SHA256SUMS 校验。设备擦除前会验证头部签名，Flash 读回 SHA-256 与兼容性检查全部通过后才启用新镜像。

本地文件升级

演示使用模拟数据。除在线来源外，也可以下载固件后在网页选择本地文件上传安装：

  1. 打开设备网页的固件更新页面。
  2. 选择已校验的 .ota.bin.signed 文件并上传。
  3. 等待写入和自动重启。升级过程中保持供电。
  4. 重新访问网页，确认版本号已更新。

旧版社区固件的无签名救援可按对应流程使用 .ota.bin.raw；支持该功能的新固件在网页勾选「允许未签名的固件」后即可上传。原厂 M1 首次迁移使用独立的 原厂上传步骤，后续正常更新仍使用签名包。

失败处理

  • 更新时暂停联动和其他业务响应，保留升级状态查询及终止。为提高成功率，更新期间减少并发访问；持续多客户端压力更新尚未通过完整验收。
  • 网页仍可访问：检查文件和网络后重试；确认型号与版本匹配。
  • 设备无法启动：按对应模块的下载器恢复方法处理，见各型号刷机文档。
  • OTA 不需要拆机。
