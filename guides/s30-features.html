S30-V1B 特色功能

单路计量插座 ORVIBO S30-V1B 使用 BL2028N／BK7231N 和 HLW8032。日常操作见 常见功能，功率规则和 M1 字段见 自动化、联动与远程显示。

来电开／关／保持

已发布 RC4 支持来电关闭、开启；“保持”需使用配套开发固件。

在「设置 → 常规 → 上电开关策略」选择：

策略 重新上电／重启后的输出
关闭（默认） 关闭
开启 开启
保持 恢复最近一次已保存的开关状态

“保持”保存实际继电器开关状态，不保存自动化正在进行的计时。本地短按优先执行，状态由后台保存；极短时间内立即断电可能来不及保存最近一次短按。网页或自动化切换前须保存状态；保存失败则不切换输出。首次启用保持策略，以当时输出作为保存状态。旧社区配置升级时保留网络、管理认证、设备名、计量倍率和累计量；旧开／关策略按原含义转换。

红蓝指示灯

下表为普通指示灯启用时的含义：

状态 蓝灯 红灯
Wi-Fi 正常，MQTT 未配置或已连接 输出开启常亮，关闭熄灭 熄灭
已配网但 Wi-Fi 断开 继续表示输出通断 快闪，亮灭各约 150 ms
Wi-Fi 正常，已配置 MQTT 但未就绪 继续表示输出通断 慢闪，亮灭各约 1 秒
未配置网络且未联网 红蓝交替，每色约 500 ms 与蓝灯交替

关闭指示灯设置会关闭上述普通状态灯效。按住按钮时，计时提示优先显示，且不受指示灯关闭或童锁影响。

本地按键与童锁

短按切换继电器，童锁只屏蔽普通短按，不能屏蔽长按恢复与计时灯语。短按后约 1.5 秒内远程控制需等待。恢复方法归入 常见功能 → 恢复。

计量读数

HLW8032 提供电压、电流、有功功率及累计电量。收到有效采样才显示相应实时值；缺失或超过约 5 秒未更新的采样显示为无数据，不能把它解释为负载功率为零。

默认电压、电流、功率倍率分别为 1.894288 / 1.0102 / 1.88835008906368，来自本型号原厂 2M.1220 固件中的固定换算系数。需要调整时，用独立参考仪表校准。

打开 设置 → 常规 → 计量校准，可分别修改三项倍率，范围为 0.001..100，支持上述系数的完整小数精度。保存后立即生效并保留至重启后。校准时使用稳定负载，与独立参考仪表分别核对三项读数。“已校准”仅表示用户保存过校准参数。

升级会自动将旧版未校准的 1.88 / 1 / 1.88 替换为原厂型号系数；手动保存过的倍率、其它系数组合及累计电量保留。Wi-Fi 重置保留倍率，恢复出厂设置恢复上述默认值。累计电量约每 5 分钟保存一次，保存配置及正常重启前也会保存；突然断电可能丢失最近约 5 分钟的累计量。

若输出已经开启但仍无计量数据，先检查状态中的计量有效性，不要通过随意放大系数制造读数。涉及计量线路检查时，先断电并移除负载，恢复串口或外接直流供电前必须断开市电。
