DAIKIN BRY88AX151K 空气检测仪

ESP32 / 4 MB Flash 版本使用同一份通用固件，自动识别 PM2005 / PM2105 和可选甲醛模块。网页与 M1 共用读数卡片、舒适度条和联动设备列表，支持本地访问、IoTCloud 与 Home Assistant。

读数与操作

  • 温湿度沿用本机原厂补偿：温度减 4.9 °C；湿度结合原始温度、混合比修正与补偿后的温度计算，限制在 0～100%。在通用设置的“温湿度补偿与校准”中可自定义温度减去值（默认 4.9°C）和湿度微调（默认 0%RH），保存后立即生效并在重启后保留；支持恢复默认。温度填正数降低读数、负数提高读数，湿度随温度补偿联动。此模型不代表独立精度验证。
  • 显示 PM2.5、PM10、CO₂、温度、湿度和 TVOC。PM2005 / PM2105 在同一帧提供两项颗粒物数据，网页分别使用独立卡片并保持单行排列；没有 PM10 数据时隐藏该项。CO₂ 传感器启动后约三分钟完成预热，预热期间显示暂无有效数据。
  • 支持该功能的固件在“通用设置 → CO₂ 模块诊断与校准”显示原始浓度、状态字节、通信错误与校准结果。当前旧版兼容协议不解码保留状态字节，故障标志显示为未知，避免误判预热。手动校准需已知且稳定至少两分钟的 400～1500 ppm 参考环境；室外不一定是 400 ppm。校准应答仅表示模块已应答，仍需与参照仪比较验证；超时显示结果未知，不自动重发。
  • 自动探测甲醛扩展；没有模块时隐藏甲醛卡片和对应实体。已识别模块后来失联时显示失效，不将旧读数作为零值。
  • 舒适度条与读数一起更新；过期读数不参与舒适度判断。TVOC 使用传感器原生 ppb 单位，显示建议参考 ≤300 ppb，超过时提示通风；此通风参考值独立于自定义指示灯阈值。颗粒物分段参考 HJ 633—2026 表 3，瞬时读数不等同于按该标准计算的 AQI。
  • 在设置页调整名称、联网信息、网页密码和指示灯。背面按钮持续按住五秒可重新打开配网热点，不清空配置。

本固件暂未驱动 OLED 和内部 GPIO26 指示灯。BRY88AA151K 的引脚及 ADC TVOC 与本板不同，不能据此认定兼容。

指示灯设置

在“设置 → 通用设置 → 指示灯规则”中启用空气质量指示灯，为 CO₂、TVOC、PM 各配置最多两组阈值，选择常亮、常灭、快闪或慢闪；PM 灯选择 PM2.5 或 PM10 为数据源，只有选中的数据参与判断。检测到甲醛模块后也可设置甲醛规则。规则重启后保留。同一项目同时命中两组时，高阈值优先；未命中或读数过期时熄灯。TVOC / 甲醛共用一颗灯，优先级依次为快闪、慢闪、常亮、常灭。

Wi-Fi 灯用于系统状态提示：未配网三长三短；Wi-Fi 断开快闪（亮灭各 150 毫秒）；已配置 MQTT 但尚未就绪时慢闪（亮灭各 1 秒）；就绪时常亮。不配置 MQTT 也能进入就绪状态，此灯独立于空气质量指示灯开关。

首次安装

在下载页选择明确包含 DAIKIN 的版本。旧版归档只有斐讯设备时，不要上传其它型号镜像。已有 0.9.x 发布仅提供完整版；v1 中枢版本尚未发布。

  1. 确认 ESP32 / 4 MB Flash 与接线，完整备份原始 Flash；备份含有联网凭据，妥善保存。
  2. 将 GPIO0 / BOOT0 在上电时拉低，进入 ESP32 下载模式。使用 ESPTool 将 daikin_BRY88AX151K.all.bin 写入 0x0。不要以 factory 镜像执行网页 OTA。
  3. 松开 BOOT0 并重新上电，连接 BRY88AX151K-AP-<MAC末六位大写> 热点（例如 BRY88AX151K-AP-AABBCC），打开 http://192.168.0.1/ 设置 Wi-Fi。长按按钮或断网后恢复的热点也使用相同名称和地址。
  4. 在路由器中查找设备 IP，通过本地网页确认读数。CO₂ 需要等待预热；未安装甲醛模块时不会显示甲醛卡片。

仅连接兼容 ESP32 的 3.3 V 串口电平，避免让 USB 转串口向设备反向供电。不确定接线时先查阅刷机前准备。完整镜像和备份恢复会覆盖 Flash，请先确认目标设备和文件。

日常更新与恢复

历史版本可能仍使用 phicomm_daikin 前缀，文件名以对应版本的下载页和 SHA256SUMS 为准。

网页的固件更新页上传 daikin_BRY88AX151K.ota.bin.signed。设备验证本项目签名、目标型号与镜像后安装，Wi-Fi 和 MQTT 配置保留。当前通过手动文件更新，不提供 URL 下载或精简包。

页面另有明确标记的未签名救援入口，仅用于可信的原始应用镜像。发布文件名为 daikin_BRY88AX151K.ota.bin.raw，本地构建文件名为 daikin_BRY88AX151K.ota.bin。无法访问网页时，可重新进入 BOOT0 下载模式，恢复原始备份或安装完整镜像。详见固件更新。

IoTCloud、Home Assistant 与 A1

按接入 IoTCloud填写同一节点的 MQTT 账号；设备以 DAIKIN BRY88AX151K 自动发现，平台提供与本地一致的读数卡片。Home Assistant 自动发现只发布实际具备的传感器。

在新版 A1 设置中添加本设备 MAC 和可选 IP。同账号 MQTT 自动建立读取授权，A1 优先通过局域网读取，网络读取不可用时使用 MQTT 数据。本设备的“联动的净化器”区域显示实际已读取的 A1；只有授权而没有读取时不会显示已连接。

A1 按当前有效的数据提供自动化选项，与检测仪型号无关。没有甲醛或读数失效时隐藏对应数据选项，已保存规则保留；控制所需数据不可用时使用 A1 的离线风速。TVOC 暂不作为 A1 调速指标。

v1.0 中枢版本开发中

hub 是独立变体，包含本地账户、MQTT TCP / WebSocket Broker、局域网 Home Assistant、上游 MQTT 客户端及巴法云转发。普通版继续用于传感器。本地账户不含邮箱或 GitHub 登录。

在设备网页点击“中枢管理”，或访问 http://设备IP/iotcloud/#/。首次使用先设置设备网页管理密码，再创建本地账户：用户名为 3–32 个英文字母、数字或下划线，密码为 8–63 字节。登录后可管理设备、上游转发、巴法云映射与 Apple 家庭。

其他设备在各自的 MQTT 设置中填写中枢 IP、端口 1883 和本地账户的 MQTT 用户名/密码；WebSocket 客户端使用 ws://中枢IP:9001/mqtt。设备管理页提供手动配置说明，Home Assistant 也可连接同一 Broker。

Apple 家庭通过 HAP 桥接，在“Apple 家庭”设置中单独启用并获取配对码；默认关闭。暂不提供 Matter。v1 尚未正式发布，下载区现有普通版不包含这些中枢功能。

普通版切换为中枢

仅声明支持此操作的新 full 普通版提供切换入口；镜像仍须符合设备实际 OTA 槽容量。此流程使用本地 HTTP 和实际的 hub 签名 OTA 文件，当前下载区的旧普通版不提供该功能。

  1. 在局域网打开设备网页，先设置网页管理密码；已有密码时沿用。升级页的“设置网页管理密码”可跳转到密码设置。
  2. 打开“设置 → 固件升级 → 高级”，选择匹配本机的 hub 签名 OTA，勾选“切换为中枢版本”。此项不能与未签名救援同时使用。
  3. 点击“上传并升级”，核对弹窗后明确确认切换。Wi-Fi、MQTT 和网页管理密码保留。
  4. 重启后重新访问设备，确认变体为 hub，点击“中枢管理”，使用原网页管理密码完成首次本地账户创建。HomeKit 默认关闭，需要时再单独启用。

普通签名升级和未签名救援仍只接受当前变体；hub → full 不支持直接 OTA。
