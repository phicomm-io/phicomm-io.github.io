大金空气质量检测（G2）

G1 没有甲醛扩展孔，G2 相比 G1 增加甲醛扩展孔；G3 增加屏幕，使用独立固件，见三代指南。默认设备名 DAIKIN G1/G2 是历史名称，自定义名称保留。下载目标 BRY88AX151K 已验证于 G2 BRY88AB151K；G1 BRY88AA151K 适配尚未确认，暂不提供安装指引。

已验证的 G2 ESP32 / 4 MB Flash 版本使用 BRY88AX151K 固件，自动识别 PM2005 / PM2105 和可选甲醛模块。网页与 M1 共用读数卡片、舒适度条和联动设备列表，支持本地访问、IoTCloud 与 Home Assistant。

日常使用选择最新兼容稳定版，RC 仅用于 Beta 测试。 实际发布版本、版本要求与累计变化见更新记录。

代际 型号 现有固件适配
G1 BRY88AA151K 适配尚未确认；暂不提供安装指引
G2 BRY88AB151K 已验证 ESP32 / 4 MB 版本，使用 BRY88AX151K 通用目标
G3 BRY88BBA15G 带屏幕，独立 ESP32 与屏幕 MCU 镜像

原厂 G2 串口备份及恢复格式见原厂备份。

读数与操作

  • 温湿度沿用本机原厂补偿：温度减 4.9 °C；湿度结合原始温度、混合比修正与补偿后的温度计算，限制在 0～100%。在通用设置的“温湿度补偿与校准”中可自定义温度减去值（默认 4.9°C）和湿度微调（默认 0%RH），保存后立即生效并在重启后保留；支持恢复默认。温度填正数降低读数、负数提高读数，湿度随温度补偿联动。
  • 显示 PM2.5、PM10、CO₂、温度、湿度和 TVOC。PM2005 / PM2105 在同一帧提供两项颗粒物数据，网页分别使用独立卡片并保持单行排列；没有 PM10 数据时隐藏该项。CO₂ 传感器启动后约三分钟完成预热，预热期间显示暂无有效数据。
  • 支持该功能的固件在“通用设置 → CO₂ 模块诊断与校准”显示原始浓度、状态字节、通信错误与校准结果。当前旧版兼容协议不解码保留状态字节，故障标志显示为未知，避免误判预热。手动校准需已知且稳定至少两分钟的 400～1500 ppm 参考环境；室外不一定是 400 ppm。校准后用参照仪检查读数；超时显示结果未知，不自动重发。
  • 自动探测甲醛扩展；没有模块时隐藏甲醛卡片和对应实体。已识别模块后来失联时显示失效，不将旧读数作为零值。
  • 舒适度条与读数一起更新；过期读数不参与舒适度判断。TVOC 使用传感器原生 ppb 单位，显示建议参考 ≤300 ppb，超过时提示通风；此通风参考值独立于自定义指示灯阈值。颗粒物分段参考 HJ 633—2026 表 3，瞬时读数不等同于按该标准计算的 AQI。
  • 在设置页调整名称、联网信息、网页密码和指示灯。背面按钮持续按住五秒可重新打开配网热点，不清空配置。

本固件暂未驱动 OLED 和内部 GPIO26 指示灯。现有真机测试与原厂串口备份来自 BRY88AB151K；AA/AB 的原厂备份按实际型号选择。

原厂补偿与颗粒物节能

支持这组功能的配套固件和前端将 PM2.5、CO₂、甲醛按原厂曲线补偿，网页、MQTT、指示灯和 A1 联动使用同一结果。PM2.5 发布范围为 1～300 µg/m³，CO₂ 为 400～3000 ppm，可选甲醛为 0.01～0.5 mg/m³；诊断保留原始读数。TVOC 保留传感器真实 ppb 和零值，使用温湿度补偿及有效基线恢复。

PM 模块默认采用原厂动态测量，启动后至少等待 36 秒并收到有效完成帧才更新读数；普通颗粒物读数有效期为 120 秒。在“通用设置 → 夜间颗粒物节能”中可开启间歇测量，默认关闭。预设时段为 23:00～07:00、UTC+8，可调整起止时间和时区；起止相同不启用时段，时间尚未同步时继续动态测量。

夜间节能每 59 分钟开启约 59 秒，等待完整采样后更新 PM2.5 和 PM10，其余时间停止测量。夜间读数最多保留一小时，页面显示的采样年龄继续增加；这适合降低夜间运行频率，但 A1 对新发生的颗粒物变化也会更晚响应。需要及时联动时关闭夜间节能。

使用这一小时有效期需同步升级 A1、M1 接收端及前端。有效期仅延长颗粒物样本的保留时间；通信中断仍按原有短超时失效，不会继续把离线设备视为在线数据源。

指示灯设置

在“设置 → 通用设置 → 指示灯规则”中启用空气质量指示灯，为 CO₂、TVOC、PM 各配置最多两组阈值，选择常亮、常灭、快闪或慢闪；PM 灯选择 PM2.5 或 PM10 为数据源，只有选中的数据参与判断。检测到甲醛模块后也可设置甲醛规则。规则重启后保留。同一项目同时命中两组时，高阈值优先；未命中或读数过期时熄灯。TVOC / 甲醛共用一颗灯，优先级依次为快闪、慢闪、常亮、常灭。

Wi-Fi 灯用于系统状态提示：未配网三长三短；Wi-Fi 断开快闪（亮灭各 150 毫秒）；已配置 MQTT 但尚未就绪时慢闪（亮灭各 1 秒）；就绪时常亮。不配置 MQTT 也能进入就绪状态，此灯独立于空气质量指示灯开关。

首次安装

在下载页选择明确包含 DAIKIN 的版本。旧版归档只有斐讯设备时，不要上传其它型号镜像。已有 0.9.x 归档仅提供完整版；v1.0.0 另提供独立的 hub 中枢变体。

  1. 确认 ESP32 / 4 MB Flash 与接线，完整备份原始 Flash；备份含有联网凭据，妥善保存。
  2. 将 GPIO0 / BOOT0 在上电时拉低，进入 ESP32 下载模式。使用 ESPTool 将 daikin_BRY88AX151K.all.bin 写入 0x0。不要以 factory 镜像执行网页 OTA。
  3. 松开 BOOT0 并重新上电，连接 BRY88AX151K-AP-<MAC末六位大写> 热点（例如 BRY88AX151K-AP-AABBCC），打开 http://192.168.0.1/ 设置 Wi-Fi。长按按钮或断网后恢复的热点也使用相同名称和地址。
  4. 在路由器中查找设备 IP，通过本地网页确认读数。CO₂ 需要等待预热；未安装甲醛模块时不会显示甲醛卡片。

仅连接兼容 ESP32 的 3.3 V 串口电平，避免让 USB 转串口向设备反向供电。不确定接线时先查阅刷机前准备。完整镜像和备份恢复会覆盖 Flash，请先确认目标设备和文件。

日常更新与恢复

历史版本可能仍使用 phicomm_daikin 前缀，文件名以对应版本的下载页和 SHA256SUMS 为准。

网页的固件更新页上传 daikin_BRY88AX151K.ota.bin.signed。设备验证本项目签名、目标型号与镜像后安装，Wi-Fi 和 MQTT 配置保留。RC6 支持在线检查与下载；已有旧版若没有该入口，先用本地签名包升级。G1/G2 不使用 G3 屏幕、字库或固件。

页面另有明确标记的未签名救援入口，仅用于可信的原始应用镜像。发布文件名为 daikin_BRY88AX151K.ota.bin.raw，本地构建文件名为 daikin_BRY88AX151K.ota.bin。无法访问网页时，可重新进入 BOOT0 下载模式，恢复原始备份或安装完整镜像。详见固件更新。

IoTCloud、Home Assistant 与 A1

按接入 IoTCloud填写同一节点的 MQTT 账号；设备以 DAIKIN G1/G2 自动发现，平台提供与本地一致的读数卡片。Home Assistant 自动发现只发布实际具备的传感器。

在新版 A1 设置中添加本设备 MAC 和可选 IP。同账号 MQTT 自动建立读取授权，A1 优先通过局域网读取，网络读取不可用时使用 MQTT 数据。本设备的“联动的净化器”区域显示实际已读取的 A1；只有授权而没有读取时不会显示已连接。

A1 按当前有效的数据提供自动化选项，与检测仪型号无关。没有甲醛或读数失效时隐藏对应数据选项，已保存规则保留；控制所需数据不可用时使用 A1 的离线风速。TVOC 暂不作为 A1 调速指标。

中枢版本

中枢使用独立的 hub 镜像。 v1.0.0 的名称同步、计量与机型支持需配套前端和目标设备版本，见更新日志。旧版传感器接口不兼容，来源设备和 M1 接收端应使用匹配版本。

中枢通过 mDNS 自动发现设备，配对后使用 UDP 通信，支持上游 MQTT 和巴法云转发。本地 Home Assistant 与 MQTT 客户端统一使用外部 broker。普通版继续用于传感器。

在设备网页点击“中枢管理”，或访问 http://设备IP/iotcloud/#/。中枢与设备网页共用管理密码和登录会话；未设管理密码时直接进入，设有密码时只需登录一次，同一标签页切换控制页与中枢页无需重复输入。可在设备设置中修改管理密码，点击“退出登录”结束当前会话。

升级到 rc.5 后不再使用独立中枢密码，已有中枢用户名、设备列表、转发与配对设置保留。中枢用户名继续用于既有主题命名空间。UDP 设备配对密码和外部 MQTT broker 账号仍分别配置。

大金自身自动出现在中枢设备列表中。已配对设备的参数与控制通过中枢 UDP 通路读取和发送；浏览器只需访问中枢。TC1 / S30 列表显示功率，计量数据过期时隐藏读数。远端页面提供已支持的控制与诊断；修改网络、管理密码、自动化或升级、备份时，打开目标设备的本地网页。

在“中枢管理”的局域网设备列表中选择发现的设备，核对型号、ID 和 IP 后，使用该设备的管理密码配对。IP 改变时需确认新地址并重新配对。原来指向中枢内置 broker 的设备，应改为连接外部 broker。

S30M-V1B 也可通过管理 API 注册并按指定 IP 配对，用于 mDNS 无法跨越的网段；中枢完成会话认证后使用该地址通信。

Apple 家庭采用实验性 HAP 桥接，默认关闭；在“Apple 家庭”设置中启用并获取配对码。暂不提供 Matter。

中枢收到新的设备名和插口名后会通知家庭控制器刷新配置，无需删除已有配对。

TC1 / S30 的每路开关同步设备侧的插口名称；在设备设置修改后，中枢会刷新名称。插口名称特征只读，Apple 家庭中的重命名仍作为本地别名。设备名称同步到 HomeKit；A1、M1 和大金的 ConfiguredName 还支持客户端经中枢改名，保存成功并读取确认后生效。使用这些名称与计量功能时，中枢需 v1.0.0 或更新版本，目标设备需 rc.6 或更新的兼容版本。名称按 UTF-8 字节计数：TC1 最多 31 字节，A1、M1、大金及 S30 最多 63 字节；配对和设备标识保持。需要修改共享设备名时，从设备设置中改名。

A1 净化器和新风使用标准空气净化器服务，提供开关、速度和自动 / 手动模式。升级时空气净化器使用独立于旧风扇的服务标识，保留配对和现有控制特征的标识。TC1 / S30 的首路开关附带整机功率（W）和累计电量（kWh）的 Eve 自定义特征；Apple 家庭不显示这些功率 / 电量自定义特征；支持 Eve 特征的第三方客户端可读取。HAP 桥接提供数据，但不能让 Apple 家庭增加读数卡片。设备网页和中枢网页可查看功率，S30 还显示电压、电流和累计电量。

A1 单独显示时使用空气净化器图标。与灯服务编组后，Apple 家庭可能选择灯作为编组主体；编组磁贴的图标由 Apple 家庭决定。需要保留空气净化器磁贴时，在家庭中分开显示。G3 通过中枢暴露有效传感器。

普通版切换为中枢

仅声明支持此操作的新 full 普通版提供切换入口；镜像仍须符合设备实际 OTA 槽容量。此流程使用本地 HTTP 和实际的 hub 签名 OTA 文件，0.9.x 普通版不提供该功能。

  1. 在局域网打开设备网页。网页管理密码可选；已有密码时使用该密码验证。
  2. 打开“设置 → 固件升级 → 高级”，选择匹配本机的 hub 签名 OTA，勾选“切换为中枢版本”。此项不能与未签名救援同时使用。
  3. 点击“上传并升级”，核对弹窗后明确确认切换。Wi-Fi、MQTT 和网页管理密码保留。
  4. 重启后重新访问设备，确认变体为 hub，点击“中枢管理”；若已设置网页管理密码，使用同一登录会话进入。HomeKit 默认关闭，需要时再单独启用。

普通签名升级和未签名救援仍只接受当前变体；hub → full 不支持直接 OTA。
