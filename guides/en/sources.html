Guide images and tools are hosted under guides/assets/. SHA256SUMS lists their checksums.

File Source
images/emw3080-pins.png MXCHIP EMW3080 pin diagram; original content retained, transparent background changed to white

images/tc1-a1-module.png, images/tc1-a1-test-points.png User-provided annotated TC1 A1 module / factory test-point images
images/a1-jlink-points.png User-provided corrected A1 J-Link wiring photo (DIO above CLK)
images/m1-scd40-wiring.png User-provided M1 / SCD40 wiring photo; handwritten 7 / 8 are GPIO signal names
tools/emw3080-openocd.zip, tools/emw3080-openocd/ Project Python 3 validation, splitting and flashing helper with modern MX1290 configuration; no third-party binaries or firmware. Requires the matching programmer and script from the original zA1 package
images/jlink-swd.png Official SEGGER SWD diagram, converted to PNG on white
images/flashplus-config.png Configuration crop from page 2 of the EMW3031 / FlashPlus manual. Used only for chip / Flash identification; use this project's erase and verification instructions
tools/FlashPlus_v1.0.10.msi Marvell FlashPlus v1.0.10 from the IoTDevice mirror, unmodified installer

Images and third-party tools remain copyrighted by their authors and vendors; hosting copies does not change their licenses. FlashPlus is not part of this project's firmware source. The EMW3031 datasheet restricts reproduction of its illustrations, so the guide links to it instead.

Operating notes

The A1 filter and power interlock note comes from zA1 Issue #3. Users reported that the purifier would not power on without its filter; the original project maintainer confirmed adding the reminder to the documentation.
