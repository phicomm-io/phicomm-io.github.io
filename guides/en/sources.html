Operating notes

The A1 filter and power interlock note comes from zA1 Issue #3. Users reported that the purifier would not power on without its filter; the original project maintainer confirmed adding the reminder to the documentation.

See Build dependencies for toolchains and SDKs.

DAIKIN and measurement references

DAIKIN wiring and PM2005 / PM2105 frames follow louliangsheng/daikin-air-sensor. PM2.5 and PM10 occupy different fields in the same reply. TVOC uses SGP30 native ppb output. The ≤300 ppb product ventilation reference matches the device indicator; see the Sensirion SGP30 datasheet and MOX output explanation. It is not a health compliance limit. Particulate display bands follow HJ 633—2026 table 3; instantaneous readings are not a calculated AQI.
