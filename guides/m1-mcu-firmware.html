M1 主控开源固件：让屏幕与蜂鸣器有更多玩法

M1 内部有两个分别升级的处理器：EMW3080 联网模块负责 Wi-Fi、网页和云端；ATSAMD20G18A 主控负责传感器、屏幕、RTC、按键与蜂鸣器。本项目开源的是后者，源码采用 MIT 许可。仅安装联网固件不会自动替换主控。

开源仓库 · 主控 Release 与下载 · 联网固件使用说明

相比原厂增加了什么

原有 PM2.5、甲醛、温湿度、时钟与亮度控制仍是基础。下面是开源主控增加的扩展；网页入口还需要配套联网固件按主控真实版本与能力开放。

能力 开源主控带来的变化 版本与条件
在实体屏幕显示 CO₂ 可替换甲醛或 PM 数字位置，或按秒交替显示；过期后恢复原读数，支持 CO₂ 灯色阈值 v0.9.2；需要外接传感器及联网模块提供有效 CO₂ 数据，原机不会凭空测出 CO₂
屏幕与蜂鸣器调试 数值覆盖、29 字节段 RAM 查询/写入、全段点亮、PWM 频率与时长控制，到期恢复正常显示 v0.9.2；通过新增 0x70 扩展协议
查询能力与运行状态 查询传感器健康、显示缓存、PM 模式和当前阈值，便于排查数据与屏幕差异 v0.9.2；配套工具或联网固件
四种提示音 轻触、确认、提示、错误四种单次音，由主控负责到期停止 v0.9.3 源码已实现，尚未发布 Release
自定义 RTTTL 音乐 写入、读取、播放、停止一首单音曲目；主控 Flash 双槽保存，重启和正常应用 OTA 后保留；配套 WebUI 可作闹钟曲目 v0.9.3 源码已实现，尚未发布 Release；最多 1024 字节、256 音符、180 秒
可审阅的升级与恢复实现 开源接收/暂存/校验流程；独立新 Boot 增加 CRC32 日志与中断后重新搬运 仅替换独立 Boot 后才有新 Boot 的校验与恢复行为；CRC 不是签名，也不是旧版回滚

原厂已有的两档污染物阈值设置不是新增能力；本项目保留其控制灯色和高档蜂鸣告警的行为，并增加配置查询。时间冒号每秒闪烁已在 v0.9.3 源码实现，但尚未确认原厂是否有同样路径，因此不把它列作原厂没有的功能。

下载与验证状态

目前已发布的最新主控版本是 v0.9.2 开发预览。下载区单独列出本仓库全部公开 Release（含 Pre-release），与 TC1 / M1 / A1 的联网固件归档分开。v0.9.3 的音乐等源码功能不能视为 v0.9.2 已包含。

当前不是已完成实机验收的稳定替代固件。 早期 oss-0.3 曾被报告无法启动；后续候选已修复看门狗时钟分频，仍需独立实机复验。主机测试、ARM 构建与模型验证不能代替外设声音、时序、真实掉电和恢复验证。请以所下载 tag 的发布说明和验证记录为准。

  • m1-mcu-ota.bin：主控应用，链接地址 0x4000，配套 JSON 与 SHA256SUMS 一起核对。
  • m1-mcu-debug-recovery.zip：应用/Boot 调试与恢复产物，各镜像地址见包内说明。
  • 主控应用升级不替换原厂 Boot。保留原厂 Boot 时不能获得新 Boot 的 CRC 与中断恢复保证。
  • 主控镜像不能填入 EMW3080 联网模块的固件更新地址。配套升级路径见主控网络升级。

原厂主控备份

提供本次分析使用的 ATSAMD20G18A 原厂 11.1.2.1 主 Flash 备份，仅适用于核对过硬件与备份范围的开发/恢复。文件为 256 KiB（262144 字节），读取时两份结果逐字节一致。它包含原厂 Boot 与应用，不包含 NVM User Row、熔丝和校准辅助区，也不是联网模块固件。
