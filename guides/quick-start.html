快速开始

本项目为已淘汰或云服务厂商停止服务的 IoT 设备提供开源固件，支持斐讯 TC1 智能排插、M1 空气检测仪、A1 空气净化器、DAIKIN BRY88AX151K 空气检测仪及 ORVIBO S30-V1B 智能插座，提供本地网页控制、MQTT 与 Home Assistant 接入。固件免费，无需厂商云服务。

v0.9.27 为稳定版；v1.0.0-rc.5 用于 Beta 测试，支持 TC1、M1、A1、DAIKIN 和 S30-V1B。 候选版完整累计变化见更新记录，下载区同时保留 0.9.x 归档。M1 的 Wi-Fi 与传感器主控独立升级；原厂主控 11.x 推荐使用开源版，17.1.2.3 / 17.x 暂不建议迁移。

首次配网

以下是社区固件的首次配网；尚在原厂固件时先看 M1 原厂配网 / A1 原厂配网。

设备上电后若未配置 Wi-Fi，会开启配网热点。用手机或电脑连接该热点，浏览器访问下表中的配网地址完成设置。

设备 首次连接的热点 配网页面
TC1（A1 硬件版本） TC1-AP-<MAC后六位> http://192.168.0.1/
M1 M1-AP-<MAC后六位> http://192.168.0.1/
DAIKIN BRY88AX151K-AP-<MAC后六位大写> http://192.168.0.1/
A1 空气净化器 A1-AP-<MAC后六位> http://192.168.0.1/
S30-V1B S30M_V1B_<MAC后六位> http://192.168.0.1/

各型号热点名称中的 MAC 后六位均为大写。旧版本的热点名称和配网地址可能不同，请核对所选 Release 的版本说明。

访问设备网页

配网成功后，设备接入家庭 Wi-Fi。通过路由器查询设备的 DHCP 地址，在浏览器访问该 IP 地址即可打开 WebUI。

WebUI 顶部可切换中文、英文及明暗主题。设置按网络、设备、自动化和维护分组；修改配置后按保存，部分网络修改会断开连接。不同设备只显示所支持的功能。

主题选择保存在浏览器本地，与你在这台设备上的选择互通。
